# C5 Hermes AI News · 方案草案

## 1. 你打算做什么？解决什么问题？

做一个 AI 早报系统，每天早上 8:00 自动抓取全球 AI 领域最新新闻（OpenAI、Google、Meta、Anthropic、国内大厂等），经 AI 编辑排版后推送到微信。

**核心问题**：AI 领域迭代太快，同学们需要每天了解最新动态，但手动刷新闻效率低、容易漏。

## 2. 你凭什么觉得这个方向有效？

- 引用 ≥1 论文/项目：Hermes Agent (Nous Research) 已提供成熟的 cron + 多平台推送架构
- 引用 ≥1 前人经验：现有 Telegram 新闻 bot 已验证"RSS 聚合 + AI 编辑"模式可行
- GitHub Trending + RSS + Tavily 实时搜索三重覆盖确保新闻完整性和时效性

## 3. Token/算力打算怎么花？

| 用途 | 预估消耗 | 频次 |
|------|----------|------|
| Tavily 搜索 (4 queries × 10 results) | ~¥0.5/次 | 每天 1 次 |
| DeepSeek V4 Pro 编辑排版 | ~¥1/次 | 每天 1 次 |
| **日均合计** | **~¥1.5** | |
| **月均合计** | **~¥45** | 远低于 ¥70 阈值 |

无需 Dr. Xiao 额外审批，用自有 API 额度即可。

## 4. 失败了怎么办？

- 如果 RSS 源大面积失效 → 扩大 Tavily 搜索 query 数量补偿
- 如果 DeepSeek API 不可用 → 降级为脚本直接输出 JSON 格式
- 如果同学反馈新闻不够新 → 缩小时间窗口至 12h，增加搜索频次
- 如果无人使用 → 分析原因（时间不对？内容不相关？），调整后重新推广
