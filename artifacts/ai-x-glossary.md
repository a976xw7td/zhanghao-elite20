## 核心概念

### 框架与思维模型

| 英文 | 中文 | 一句话定义 | 类比 |
|------|------|------------|------|
| AI+X 3D Framework | AI+X 三维框架 | 用三个维度定位你的学习：专业领域（X）、AI工具（AI）、自我反思（S） | 你在一张三维地图上的坐标——X是你的专业方向，AI是你的工具高度，S是你的成长速度 |
| The Diagonal | 对角线 | 三轴同时移动时产生的独特能力，是"Elite"的真正含义 | 三道菜分开吃是温饱，同时烹饪是厨师——对角线就是你的厨艺 |
| Acceptance Criteria | 验收标准 | 在开始行动之前，明确定义"做到什么程度算完成" | 跑100米前先知道终点线在哪——不然你永远在跑 |

### 工作方法

| 英文 | 中文 | 一句话定义 | 类比 |
|------|------|------------|------|
| KSTAR Loop | KSTAR 循环 | 五步思维框架：盘点知识→认清处境→定义任务→执行行动→复盘结果 | 做实验的五个步骤——假设、准备、实验、记录、分析，缺一不可 |
| K — Knowledge | 知识 | 完成任务前需要知道的信息和背景 | 去图书馆前先查目录——你知道什么、不知道什么？ |
| S — Situation | 情境 | 当前的状态、约束条件和限制 | 你的起跑线位置——你站在哪、手里有什么、不能做什么？ |
| T — Task | 任务 | 具体要完成的事，以及它的验收标准 | 工作指令单——要做什么 + 怎样算做好 |
| A — Action | 行动 | 实际执行的步骤，包括具体的提示词和操作 | 做实验的过程——每一步都记录，错了可以回看 |
| R — Result | 结果 | 发生了什么、是否符合预期、学到了什么 | 实验报告——不只是"成功或失败"，还有"为什么" |

### 工具与环境

| 英文 | 中文 | 一句话定义 | 类比 |
|------|------|------------|------|
| Workspace Folder | 工作区文件夹 | AI 被允许读写的文件夹，是 AI 的工作边界 | AI 的"家"——它在家里什么都能做，但出不了门 |
| GitHub | GitHub | 基于 Git 的代码托管平台，也可以作为任何项目的版本控制笔记本 | 实验室记录本的数字版——每一页都有日期、有签名、不可涂改 |
| Commit | 提交 | 将一次有意义的改动连同说明信息保存到 Git 历史中 | 在实验记录本上写一页新记录——写日期、写做了什么、签名 |
| Prompt Engineering | 提示词工程 | 设计和优化给 AI 的输入指令，以获得更好的输出 | 给学徒下指令——说"做个东西"和说"用木头做一把40厘米高的椅子，四条腿，能承重80公斤"结果完全不同 |
| Skill | 技能 | 为 AI 预置的专业领域扩展包，包含工具和知识 | 食谱卡——你不需要会做这道菜，把卡给厨师（AI），它按卡做 |
| SKILL.md | 技能说明文件 | Skill 的说明书，AI 通过读取它来学会如何完成某类专业任务 | 食谱卡上的具体配方——材料、步骤、火候、注意事项 |
| Vibe-Coding | 氛围编程 | 以 AI 为核心的迭代式创作方式：提示→迭代→验证→交付 | 爵士即兴——不是照谱弹（传统编程），也不是乱弹（外包判断），而是有方向的即兴创作 |
