## 核心概念

- **KSTAR 循环**：K(知识) → S(情境) → T(任务) → A(行动) → R(结果)
- **AI+X 三维框架**：X轴(领域) × AI轴(杠杆) × S轴(自我) = 对角线能力
- **Vibe-Coding**：提示 → 迭代 → 验证 → 交付，像爵士即兴而非视奏
