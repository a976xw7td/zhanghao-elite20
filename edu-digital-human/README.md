# 智引灵 AI 导航导师

第三届"教育数字人大赛——我和数字人的故事"参赛作品。

## 安装

1. 打开 Chrome，地址栏输入 `chrome://extensions`
2. 开启右上角"开发者模式"
3. 点击"加载已解压的扩展程序"
4. 选择 `extension` 文件夹
5. 点击工具栏的扩展图标，在侧边栏填入 DeepSeek API Key + ASR API Key

## 使用

- **语音**: 按住侧边栏或页面浮窗麦克风按钮说话，松开发送
- **文字**: 点击浮窗 ✏️ 按钮，输入文字回车
- 数字人高亮目标元素 + 语音指引
