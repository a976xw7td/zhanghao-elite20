# D4-P3 — 任务拆解：完成学习周报

## 提示词

```
我需要完成一份关于"AI+X Elite 20 第一周学习"的周报。
请帮我把这个任务拆解为5个具体步骤，每步不超过一句话。

背景：
- 我有5天的零散笔记（D1-D5）
- 周报最终提交到 GitHub
- 面向对象：课程 instructor

要求：
- 每步必须是可直接执行的动作（含动词）
- 每步不超过20个字
- 不要出现"第1步/第2步"这种序号——用自然的时间顺序即可
```

## AI 响应

盘点五天笔记中每日的关键收获。提取三个最重要的共同主题。用结构化段落组织成初稿。补充一个简短的个人反思段落。检查格式和字数后推送到GitHub仓库。

## 反思

- ✅ 拆解为5步，每步都是可执行动作
- ✅ "盘点→提取→组织→补充→检查"顺序自然合理
- ⚠️ 过于通用化——如果能结合我的具体专业（信息管理）给出更有针对性的建议会更好
- 📝 改进：提示词中可以加入"结合信息管理专业的视角"来让输出更个性化
